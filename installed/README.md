# installed/ — snapshot of live deployment

This directory mirrors what `install/install.sh` produces on this machine, minus
runtime data (venvs, `state.db`, `work/`, logs) and secrets (real
`telegram.json`). It exists purely as a backup so the running system can be
reconstructed if the machine or Application Support directory is wiped.

**These files are copies.** The authoritative source lives in the sibling
directories (`daemon/`, `cli/`, `swiftbar/`, `launchd/`). If you edit anything
here it will be overwritten the next time `install.sh` runs.

## Layout

| Path in this snapshot | Actual install location |
|---|---|
| `installed/app_support/songcatcherd.py` | `~/Library/Application Support/Songcatcher/songcatcherd.py` |
| `installed/app_support/shazam_helper.py` | `~/Library/Application Support/Songcatcher/shazam_helper.py` |
| `installed/app_support/telegram.json.example` | `~/Library/Application Support/Songcatcher/telegram.json` (real one has the token — gitignored) |
| `installed/swiftbar_plugins/songcatcher.5s.sh` | `~/Library/Application Support/SwiftBar/Plugins/songcatcher.5s.sh` |
| `installed/launchd/com.thehub.songcatcher.plist` | `~/Library/LaunchAgents/com.thehub.songcatcher.plist` (with absolute paths already substituted) |
| `installed/bin/songcatcher` | `~/bin/songcatcher` |
| `installed/bin/songcatcher-split` | `~/bin/songcatcher-split` |

## Not included (regenerated by install.sh or generated at runtime)

- `~/Library/Application Support/Songcatcher/venv/` — Python venv (FastAPI, uvicorn, pydantic, mutagen)
- `~/Library/Application Support/Songcatcher/shazam_venv/` — isolated venv for shazamio
- `~/Library/Application Support/Songcatcher/state.db` — SQLite queue + job history
- `~/Library/Application Support/Songcatcher/work/` — partial downloads
- `~/Library/Logs/Songcatcher/` — daemon logs
- `~/Desktop/Music/` — actual output MP3s
